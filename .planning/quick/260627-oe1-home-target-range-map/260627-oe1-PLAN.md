# Add a static target-range map to the home page

## Goal

Show the site's geographic coverage area ("target range") on the home page as a
small, **static** map floated to the right of the intro prose.

## Key finding

The authoritative target-range boundary already lives in the codebase. The
species occurrence map (`src/components/pnwm-occurrence-map.ts`) shades everything
*outside* the Pacific Northwest using a polygon "hole" annotated
`source: pnwinsects-app`:

```
[[60, -140], [60, -120], [53.8, -120], [45, -109], [39, -109], [39, -125]]
```

No need to reverse-engineer the reference site (https://pnwmoths.biol.wwu.edu/);
this ring is the same boundary. It's now extracted to a shared module
(`src/components/pnw-region.ts`, `PNW_REGION_RING`) and reused by both the
occurrence map and the new range map's generator.

## Decisions

- **Static inline SVG, not an interactive map.** An earlier pass used a
  non-interactive Leaflet map, but Leaflet's attribution footer overlapped the
  southern edge of the region and it pulled tiles/JS onto the home page. The SVG
  is a plain image: no JS, no tiles, no attribution overlay.
- **Real basemap, generated from data.** `scripts/generate-range-map.ts` renders
  US state + Canadian province outlines (Natural Earth 1:50m admin-1), clips them
  to the region bbox, projects them (equirectangular with cos-latitude
  correction), and highlights `PNW_REGION_RING` on top → `src/images/pnw-range.svg`
  (~44 KB, ~14 KB gzipped). The region is read from the shared module, so
  re-running keeps the map in sync.
- **Generation is manual, not in `npm run build`.** It needs network (Natural
  Earth fetch); the site build stays offline/deterministic. The committed SVG is
  the artifact. `npm run generate:range-map` regenerates it.
- **Asset lives in `src/images/` (force-added).** That dir is gitignored as a
  former Git-LFS path, but site *chrome* (the banner `header.png`) is committed
  there the same way; only species photos go to the CDN.
- **Placement / layout:** floated right of the intro prose (user request), full
  width on narrow viewports.

## Tasks

1. **Extract shared region ring** — `src/components/pnw-region.ts`
   (`PNW_REGION_RING`); `pnwm-occurrence-map.ts` imports it. *(done)*
2. **SVG generator + asset** — `scripts/generate-range-map.ts`,
   `src/images/pnw-range.svg`, `npm run generate:range-map`.
3. **Home page + styles** — `<figure class="home-range-map">` with an `<img>` in
   `src/index.njk`; `.home-range-map` rules in `theme.css`.

## Verification

- `npm run typecheck` passes (browser + node).
- `npm run build:eleventy` succeeds; home page renders the figure; the SVG ships
  (Vite fingerprints it into `/assets/`).
- SVG rasterized and eyeballed: recognizable PNW with state borders and the range
  highlighted.
