| Boundary | Description |
|----------|-------------|
| untrusted PR author → pr-check.yml runner | `pr-check.yml` triggers on `pull_request` (including forks); the runner checks out and executes PR code via `npm ci` + build + the new gate commands |
| GitHub Actions runner → repo secrets | Whether the new steps expose secrets to untrusted PR code |
| pinned actions → supply chain | Whether new third-party actions are introduced (they are not) |

|-----------|----------|-----------|-------------|-----------------|

Fork PR code already runs `npm ci` + build today; adding typecheck/test/guard does not expand the secret surface. LOW (no change). |
| T-38-02-SECRET | Information disclosure | new steps + `GITHUB_TOKEN` | mitigate | None of the four new steps read secrets or `GITHUB_TOKEN`; they invoke deterministic local commands. `permissions` stays read-only. No `env:` secrets added. LOW. |
| T-38-02-SC | Tampering | new `uses:` action SHAs | mitigate | NO new `uses:` actions added — all four new steps are `run:` steps (RESEARCH.md confirms). Existing action pins (checkout, setup-node, cache, configure-pages, etc.) are untouched, so no new supply-chain surface. N/A. |

LOW. |
