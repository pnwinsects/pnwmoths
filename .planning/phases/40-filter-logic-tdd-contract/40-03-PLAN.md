<objective>
Implement the pure filter-logic TDD contract for the Identify feature (IDENT-04): two exported
functions in `src/_lib/key-filter.ts` and a `node --test` suite in `src/_lib/key-filter.test.ts`
proving the locked D-01..D-04 semantics before any UI is built.

`buildQuestionGroups()` groups the 237 character-states by `character.question` (all 55 question
strings are globally unique — verified). `computeMatching()` applies the D-03 elimination
predicate via the byte-wise bitset keepMask, ORing within a question and ANDing across questions,
returning `{ matchedSlugs: string[], count: number }`.

The critical correctness property: the naive `result &= OR(selected bitsets)` (STACK.md
pseudocode) is WRONG — it eliminates unscored (all-zero) species. The correct per-question mask
is `result &= (selectedUnion | ~opposingUnion)` applied byte-by-byte with `~` masked to `& 0xff`.

Purpose: Lock the filter math as tested pure functions so Phases 41–42 build UI against a proven,
importable contract.
Output: `src/_lib/key-filter.ts` (logic + types), `src/_lib/key-filter.test.ts` (8 TDD cases);
`npm test` and `npm run typecheck` green.
</objective>
