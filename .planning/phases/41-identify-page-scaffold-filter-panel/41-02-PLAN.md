<objective>
Create the `/identify/` Eleventy route, the `src/_data/keyMatrix.ts` loader that feeds it, and the navigation link — delivering a navigable page with the character hierarchy inlined for the panel and a complete no-JS static degradation (character text + 1,192 Family→Genus species links).

Purpose: IDENT-01 (the route + nav link) and IDENT-06 (no-JS degradation) are the static-HTML half of the phase. The page must render and degrade correctly BEFORE the interactive panel (Plan 03) reads its inlined `#key-char-data`. The loader mirrors the established `src/_data/taxon.ts` → Browse pattern; the template mirrors `src/browse/index.njk`'s inline-JSON + `<noscript>` pattern. Because `KeySpecies` objects in `data/key-matrix.json` do NOT carry `family`, the loader joins `data/species.csv` to attach family and pre-groups species (Family → Genus) so the Nunjucks template iterates a ready structure (avoiding the `{% set %}`-inside-`{% for %}` persistence trap).

Output: `src/_data/keyMatrix.ts`, `src/identify/index.njk`, and one new nav `<li>` in `src/_includes/base.njk`.

Decisions implemented: D-07 (no-JS species list = 1,192 matched species as Family→Genus links), D-08 (no-JS character hierarchy as plain nested text, no form controls). Inline-JSON scope per Claude's-Discretion (characters+species, no bitsets).
</objective>
