CDN host is a fixed constant (RESEARCH Security Domain V5). |

| T-43-08 | Denial of Service (self-inflicted) | build-key throwing on a bad curator `char_id` | mitigate | Out-of-range / non-integer `char_id` is a non-fatal `console.warn` + skip (D-08); the build never fails on curator CSV mistakes. |
