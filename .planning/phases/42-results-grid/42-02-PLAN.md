| data → DOM: `nav_image` filename → CDN `<img src>` | Build-time-sourced filename interpolated into a URL |
| user → DOM: filter selection → rendered grid | Selection drives which cards render; all values are app-controlled, not free text |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-42-03 | Tampering | fetched `key-matrix.json` shape | mitigate | `validateKeyMatrix()` (Zod + bitset-length guard) runs before use; on failure soft-degrades to prompt state (no crash) |
| T-42-04 | Injection (Tampering) | `nav_image` filename → CDN `<img src>` | mitigate | URL built via `buildCardUrl` which uses `encodeURIComponent(navImage)`; all markup via Lit `html` templating — no `innerHTML`, no unsanitized string interpolation |
| T-42-05 | Tampering | species link href / matrix fetch path | mitigate | `path-prefix` ("{{ '/' | url }}") drives both; never hardcoded "/pnwmoths/" — prevents broken/wrong-origin links on GitHub Pages |
| T-42-06 | Information Disclosure | none — no auth, no secrets, no PII, no user input persisted | accept | Static client-side feature; all data is public reference data from the project's own CDN |
