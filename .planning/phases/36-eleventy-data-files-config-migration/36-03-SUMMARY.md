## Approach

All three files read local filesystem data (CSV, JSON) with no DuckDB boundary. Per PATTERNS §file-I/O path: local interface for emitted shape, no `getRowObjectsJS()` guard.

- **speciesPhotos.ts**: Trivial conversion. `import type { SpeciesPhoto }` from `src/types/`. Single `as Record<string, SpeciesPhoto>` cast of build-locked JSON. `existsSync` soft-fail (`console.warn` + `return {}`) preserved.
- **images.ts**: Local `interface ImageRow` captures the actual emitted shape: `photographer: string|null` (via `row.photographer || null`), numeric fields as `number|null` via `toInt`/`toFloat`. Under `noUncheckedIndexedAccess`, index access `row['field']` returns `string|undefined`; `?? ''` coalesce used for string fields, `|| null` for optional-null fields. `parseCSV` typed as `(text: string): Record<string, string>[]`.
- **plates.ts**: Local `interface PlateEntry` covers both code paths. `DESCRIPTIONS: Record<string, string>` annotation prevents `noUncheckedIndexedAccess` error on `DESCRIPTIONS[number]`. `bySlug: Map<string, PlateEntry & { dirName: string }>`. JSON fallback path casts `JSON.parse(...)` as `PlateEntry[]` (committed file; build-locked). Both `parseDirName`/`toSlug`/`readDimensions` annotated with explicit parameter and return types.
