## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-37-02 | Tampering | loadParquet ← records.parquet (CDN version skew / wrong column schema) | mitigate | `parquetMetadata(arrayBuffer)` O(columns) validator checks all 14 expected column names from the footer and throws on any missing column (D-05); no silently-wrong occurrence data renders — interactive layer falls back to empty state, static HTML still renders |
| T-37-03 | Tampering | oversized/malformed Parquet payload | accept | hyparquet already parses the footer defensively; the file is whole-fetched (no range requests by design); CDN is bunny.net object storage (not user-controlled).
